# 🌿 AveiroHub - Plataforma de Produtos Locais e Sustentabilidade

Portal web para valorização e comercialização de produtos locais de produtores da região de Aveiro, promovendo sustentabilidade, consumo consciente e economia circular.

## 📂 Estrutura do Projeto
- `index.html`: Página principal (Mercado de Produtos Locais)
- `produtos.html`: Catálogo de produtos
- `sobrenos.html`: História e propósito da plataforma
- `sustentabilidade.html`: Iniciativas ecológicas e impacto
- `perguntasfrequentes.html`: FAQ para clientes e produtores
- `signin.html` & `php/`: Módulo de autenticação e gestão de produtores
- `features-posterior/`: Recursos em desenvolvimento e pontes de recolha

## 🛠️ Tecnologias
- HTML5, CSS3, JavaScript
- Leaflet.js (Mapas interativos)
- PHP (Backend / Autenticação)
